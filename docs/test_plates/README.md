# 見分けやすさ確認カード（P型）

デモ動画で補正の効果を見せるための、自作の数字のカード。
**医療的な色覚検査ではない。** 「検査」「診断」とは呼ばず、「見分けやすさ確認カード」と呼ぶ。

## ファイル

| 場所 | 内容 |
| --- | --- |
| `plates/00_見本_12.png` | 誰でも読める見本。最初に見せて、カードの見方を伝える |
| `plates/01_74.png` 〜 `06_8.png` | P型の人には補正なしでは読めず、補正ありでは読めるカード |
| `comparisons/比較_*.png` | 説明用の4分割画像。元の画像／補正後 × 一般色覚の見え方／P型の見え方（シミュレーション） |
| `generate_test_plates.py` | 上の画像を作るスクリプト |

作り直すときは、リポジトリのルートで次を実行する（Python、Pillow、numpy が必要）。

```
python docs/test_plates/generate_test_plates.py
```

乱数の種を固定しているので、何度実行しても同じ画像になる。

## 色の決め方

- 背景は緑（`#527906` を中心に明るさ違いで4色）、数字は橙茶（`#BF6402` を中心に4色）。
- 数字の色は、背景の色を「P型の見え方のシミュレーション（Machado 2009）では変わらない方向」にずらして作っている。そのため、P型の見え方では数字と背景の色差がほぼ 0 になる。
- ドットの明るさのばらつきは、数字と背景で同じにしている。明るさの違いだけで数字が読めてしまわないようにするため。
- 補正後の画像は、アプリのシェーダー（`lib/features/shader/shaders/correction.frag`）と同じ計算で作っている。

| 色差（ΔE） | 値 |
| --- | --- |
| 一般色覚で見たとき | 62.5 |
| P型で見たとき（補正なし） | 0.0 |
| P型で見たとき（補正あり） | 46.7 |

ΔE の目安：2〜3 で「よく見ると分かる」、10 以上で「別の色」。

## 使い方（デモの撮影）

1. **紙に印刷する**のがおすすめ。モニターに映してカメラで撮ると、縞模様（モアレ）が出やすい。印刷の色は、プリンターによって多少変わる。
2. 最初に `00_見本_12.png` を見せて、「ドットの中の数字を読む」ことを伝える。
3. **補正なしと補正ありで、別のカードを使う**（同じカードだと、1回目で答えを覚えてしまう）。例：補正なしで 01〜03、補正ありで 04〜06。
4. 照明・距離・端末（Pixel 9a）をそろえる。

一般色覚の人には、補正なしでも数字が読める。観客に効果を伝えるときは、`comparisons/` の4分割画像の下の段（P型の見え方）を使う。

## 著作権について

ドットの配置は乱数で、色は行列の計算で決めていて、既存の検査表（石原式など）の絵柄は使っていない。
「石原式」とは名乗らないこと。

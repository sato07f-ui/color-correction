# 色名データ

## jis269.json

JIS 慣用色名 269 色のデータ。色名表示（F-05）の慣用色名の判定に使う。

| 項目 | 内容 |
| ---- | ---- |
| 出典 | 日本語版ウィキペディア「JIS慣用色名」<br>https://ja.wikipedia.org/wiki/JIS慣用色名 |
| 取得元 | mrcl6174/iro-jiten（`reference/jis269.json`）<br>https://github.com/mrcl6174/iro-jiten |
| ライセンス | CC BY-SA 4.0<br>https://creativecommons.org/licenses/by-sa/4.0/deed.ja |
| 変更点 | なし（そのまま使用） |
| 取得日 | 2026-11-02 |

### 形式

```json
{
  "hex": "#F9A1D0",       // 色（sRGB の16進数）
  "jis": "とき色",         // JIS の慣用色名
  "link": "鴇色",          // ウィキペディアの記事名
  "munsell": "7RP 7.5/8"  // マンセル値
}
```
